2. Description of Services

BitForge provides an integrated, non-interest-bearing custodial wallet utility within Discord that enables users to:

  • Generate unique, permanent cryptographic deposit addresses for supported cryptocurrencies (USDT on Polygon, SOL on Solana, BNB on BSC, ETH on Ethereum, BTC on Bitcoin, and LTC on Litecoin).
  • Receive on-chain crypto deposits credited to an internal, off-chain accounting ledger.
  • Send instantaneous, zero-gas social tips to other Discord users.
  • Request on-chain withdrawals to external third-party blockchain wallets.
  • View real-time cryptocurrency market prices and portfolio metrics.

3. Custodial Wallet & Account Security

Custodial Architecture Notice: BitForge manages cryptographic keypairs on behalf of users to allow instantaneous, zero-gas tipping within Discord communities. Balances displayed in /balance represent off-chain database ledger credits.
  1. Custodial Model: When you deposit funds into your BitForge deposit address, the underlying assets are held in custodial vault wallets managed by BitForge infrastructure.
  2. Key Security: BitForge encrypts all generated wallet private keys at rest using industry-standard AES-256-GCM / Fernet authenticated encryption. Decryption occurs exclusively in volatile server memory when executing authorized transactions.
  3. Discord Account Responsibility: You are solely responsible for securing your Discord account. Any transaction initiated through your authenticated Discord ID (including unauthorized transactions resulting from account compromise, SIM swapping, or phishing) will be deemed authorized by you.

4. Deposits & Minimums

  1. Supported Networks & Tokens: You must only send supported assets on their designated networks:
    • USDT: Polygon PoS (ERC-20 with automated POL gas sponsorship)
    • SOL: Native Solana Network (SPL)
    • BNB: BNB Smart Chain (BSC BEP-20 / EVM)
    • ETH: Ethereum Mainnet (Native ERC-20)
    • BTC: Bitcoin Mainnet (SegWit / Native P2PKH)
    • LTC: Litecoin Mainnet (Native P2PKH)
  2. Unsupported Tokens: Sending unsupported tokens, using wrong networks, or sending below minimum network dust thresholds may result in permanent loss of funds. BitForge cannot recover incorrectly routed deposits.
  3. Deposit Detection: An autonomous background poller queries RPC nodes every 45 seconds to scan for deposits. Blockchain network congestion may delay confirmation times.

5. Withdrawals & Network Fees

  1. Dynamic Withdrawal Fees: All external on-chain withdrawals incur a network processing fee covering blockchain miners/validators gas and vault maintenance. Fees are clearly displayed before confirming a withdrawal.
  2. Address Accuracy: Blockchain transactions are irreversible. If you provide an incorrect destination address via /withdraw, your funds cannot be recovered.
  3. Zero-Loss Withdrawal Guarantee: Off-chain balances are never deducted on node timeouts, invalid destination formats, or unconfirmed broadcasts. Debits occur only upon valid on-chain broadcast hash generation.

6. Social Tipping & Irrevocability

Irrevocability Notice: All tips executed via /tip or $tip are transferred instantly between internal off-chain ledger accounts. All tips are final, irrevocable, and non-refundable. BitForge staff cannot reverse tips sent to the wrong recipient.
