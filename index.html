Architecture Deep Dive

Built with True Cryptography

No hash truncations, no pseudo-addresses. BitForge implements raw elliptic curve derivations and bank-grade authenticated encryption at rest.

STEP 01

Raw Mathematical Key Derivation

EVM addresses derived via eth_account. Solana via raw 32-byte Ed25519. BTC & LTC via pure SECP256K1 + SHA256 + RIPEMD160 + Base58Check with correct version bytes (0x00 & 0x30).

STEP 02

Authenticated Fernet AES-256

All custodial private keys are encrypted at rest using AES-256 in CBC mode with HMAC SHA-256 authentication. Decrypted strictly into volatile server memory upon withdrawal broadcast.

STEP 03

45s RPC Poller Daemon

Autonomous background daemon queries blockchain nodes every 45 seconds. Incoming deposits are flagged with unique idempotency keys in processed_deposits to prevent double credits.

STEP 04

Zero-Loss Protection Engine

User off-chain balances are never deducted on RPC timeout or unconfirmed broadcast. If an on-chain transfer fails, your funds remain 100% intact with zero balance degradation.
